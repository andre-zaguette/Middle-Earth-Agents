# Skill: Architecture

## When to use
Use for system design, module boundaries, migrations, and technical decisions.

## Procedure
1. Define the problem and constraints.
2. Identify current architecture.
3. Compare options.
4. State tradeoffs.
5. Prefer reversible decisions.
6. Record decisions as ADRs when relevant.

## Output
- Context
- Options
- Decision
- Tradeoffs
- Follow-up work
