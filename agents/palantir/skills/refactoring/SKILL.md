# Skill: Refactoring

## When to use
Use when improving code structure without changing behavior.

## Procedure
1. Lock behavior with tests.
2. Make small mechanical changes.
3. Run checks after each meaningful step.
4. Avoid mixing refactor with feature work.
5. Preserve public interfaces unless explicitly changing them.

## Output
- Refactor goal
- Safety checks
- Patch sequence
- Risks
