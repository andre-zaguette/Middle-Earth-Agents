# Skill: Debugging

## When to use
Use when diagnosing failing tests, runtime errors, regressions, flaky behavior, or production bugs.

## Procedure
1. Reproduce the issue.
2. Capture the smallest failing case.
3. Form one hypothesis at a time.
4. Inspect logs, stack traces, recent changes, and boundaries.
5. Patch the cause, not the symptom.
6. Add a regression test.

## Output
- Reproduction
- Root cause
- Fix
- Regression coverage
