1. Check relevant skills in ./skills.
2. If task involves Codex skill routing, check `./skills/codex-routing/SKILL.md`.

4. Prefer existing project conventions.
5. Keep changes small.
6. Add or update tests.
7. Document recurring lessons back into ./skills or ./vault.

- Prefer diffs and patches.
